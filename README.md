# Estudo-de-caso---Spotify
Análise exploratória de dados (EDA) sobre o desempenho de playlists editoriais do Spotify. Investigação de fatores associados ao volume de streams, presença em playlists e charts, características das músicas e desempenho multiplataforma, visando gerar insights para a estratégia de curadoria e tomada de decisão baseada em dados.
